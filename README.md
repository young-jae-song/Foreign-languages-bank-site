다국어 문제풀이 웹 서비스

(Node.js 기반 관리자·일반 사용자 분리형 학습 시스템)

1. 프로젝트 개요

본 프로젝트는 Node.js 기반 웹 서버와
Start Bootstrap SB Admin 2 템플릿을 활용하여 구현한
다국어 문제풀이 웹 서비스입니다.

관리자와 일반 사용자의 역할을 명확히 분리하여

관리자는 문제 및 사용자 관리

일반 사용자는 로그인 후 즉시 문제 풀이

가 가능하도록 설계되었습니다.

2. 서비스 주요 특징

로그인 기반 사용자 분리 (일반 / 관리자)

영어 · 일본어 · 중국어 각 100문제씩, 총 300문제 기본 탑재

관리자 페이지를 통한 문제 관리

Node.js 서버 실행 기반 구조

초기 사용자 테스트를 위한 공용 테스트 계정 제공

3. 프로젝트 구조
startbootstrap-sb-admin-2-gh-pages/
├─ server.js    
├─ package.json
├─ index.html             # 로그인 페이지 (서비스 시작점)
├─ charts.html            # 관리자 문제 관리 페이지
├─ js/
├─ css/
├─ vendor/
└─ README.md


⚠️ server.js가 위치한 폴더가 프로젝트 루트입니다.

4. 실행 환경

Node.js: v18 이상

npm: Node.js 설치 시 자동 포함

OS: Windows / macOS

Browser: Chrome 권장

5. 실행 방법
5-1. Node.js 설치 확인
node -v
npm -v


버전 번호가 출력되면 정상입니다.

5-2. 프로젝트 폴더 열기 (중요)

Visual Studio Code에서 아래 폴더를 직접 열어야 합니다.

캡스톤디자인/startbootstrap-sb-admin-2-gh-pages


❌ 상위 폴더(캡스톤디자인) 실행 시 서버 오류 발생
⭕ server.js가 바로 보이는 폴더 실행 필수

5-3. 서버 실행
node server.js


정상 실행 시:

Server running on http://localhost:3000

5-4. 서비스 접속

브라우저에서:

http://localhost:3000

7. 일반 사용자 기능 설명

일반 사용자는 로그인 후 다음 기능을 이용할 수 있습니다.

문제 풀이 화면 접근

언어별 문제 선택

영어 100문제

일본어 100문제

중국어 100문제

관리자 페이지 접근 불가 (권한 분리)

관리자가 문제를 등록하지 않아도
기본 문제 데이터가 탑재되어 있어 즉시 사용 가능합니다.

8. 관리자 기능 설명 (charts.html 기준)

관리자 페이지는 SB Admin 2 템플릿의 좌측 네비게이션 바를 기반으로 구성되어 있으며,
다음과 같은 기능을 제공합니다.

13. 유의 사항

서버 실행 없이 HTML 파일을 직접 열 경우 정상 동작하지 않습니다.

반드시 Node.js 서버 실행 후 접속해야 합니다.

테스트 계정은 평가 편의를 위한 계정입니다.
